# Maximus AI — Project Presentation

A PowerPoint presentation introducing **Maximus AI**, an AI-powered productivity assistant portfolio project.

## What's included
- `Maximus_AI_Project_Presentation.pptx` — editable 12-slide presentation
- `README.md` — this project overview

## Project features covered
- Smart Email Generator
- Meeting Notes Summarizer
- AI Task Planner
- Research Assistant
- Prompt engineering and responsible AI practices
- Prototype test results and future improvements

## Upload to GitHub
1. Download and unzip `Maximus_AI_GitHub_Package.zip`.
2. Open GitHub and create a new repository (for example, `maximus-ai-project`).
3. Select **Add file → Upload files**.
4. Upload the files from this folder, then commit the changes.

## Note
This repository package contains the project presentation, not the interactive web app source code.
